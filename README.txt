# Rota Solidária — redesign no visual do Protótipo 

Cada arquivo CSS possui, no início, as configurações básicas utilizadas no protótipo, como variáveis de cores, fontes, cabeçalho, rodapé, botões e badges. Dessa forma, cada página funciona de forma independente, sem depender de um arquivo CSS geral. Após essa parte, ficam os estilos específicos de cada página.

Paleta utilizada no protótipo:
--brand:#B4232A
--bg:#FAF9F8
--surface:#FFFFFF
--border:#E4E0DC
--text:#1A1817
--text2:#57514E
--text3:#8A827E

Também são utilizados tons específicos para indicar situações de sucesso, alerta e informação.

Tipografia utilizada:
* **Archivo** — títulos
* **IBM Plex Sans** — textos e elementos da interface
* **IBM Plex Mono** — rótulos e códigos

As fontes são carregadas pelo Google Fonts.

Os ícones utilizados na interface são da biblioteca **Material Symbols Rounded**.

A pasta `assets/` contém os arquivos de imagem utilizados no projeto, incluindo a imagem de doação e o favicon.
